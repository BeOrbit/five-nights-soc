How we work the SOC inbox overnight

1. The job

Employees forward anything that looks off to the SOC inbox. You work the queue one email at a time, oldest first. For each one, make a call:

  • Report it if it's phishing. It gets pulled from every mailbox.
  • Trust it if it's legitimate. It goes back to the employee.

Every email you close moves the clock. Clear the queue and you've made it to 6:00 AM.

2. Inspect before you decide

Display names lie. Before you make a call, check:

  • The sender. Hover the name to see the real address. On a tablet or phone, tap it.
  • Every link. Hover or tap to see where it actually goes. The text of a link means nothing.
  • Attachments. Hover or tap to see the full file name and type. Watch for double extensions.

3. Flag what's wrong

When something in an email is a red flag, click it to flag it. On a touch screen, tap it once to inspect and again to flag. Click or tap again to take the flag off.

Flag what you can defend. Flagging everything costs you.

7. Forensic cases (Night 2 on)

Some nights there's no inbox. You get a case number, a read-only SSH session on a server we think was broken into, and a case file to fill out before 6:00 AM.

  • The server is evidence. The session is read-only: anything that would change a file is refused, and network tools are switched off so you never touch the attacker's systems.
  • Every command costs time. Each one moves the clock 5 minutes, so you get about 72 before the day crew takes over. Typos, help, history, and clear are free.
  • Start with the case notes in your home folder, then the logs in /var/log. Files whose names start with a dot are hidden from a plain ls; use ls -a.
  • Narrow it down. grep, head, and tail read from a pipe, so cat /var/log/syslog | grep CRON | tail -n 5 works. One command at a time: no ; or &&.
  • Evidence logs itself. When a key piece of evidence appears on your screen, it's added to the evidence log and you earn XP. How you got it there doesn't matter.

8. The case file

The case file sits next to the terminal. Fill it in as you go. Each field has a ? tip if you're not sure what it's asking. When you're confident, file the report; that closes the session. At 6:00 AM whatever you've filled in is filed as is, and blank answers count as wrong.
